## Procedencia

- Sitio: [ecomapwebproyect.netlify.app](https://ecomapwebproyect.netlify.app).
- Rutas: `/nacional`, `/insa`, `/estadisticas` y `/login`.
- Tema: oscuro, siguiendo la preferencia del sistema durante la captura.
- Formato: JPEG, obtenido directamente del navegador.
- Las vistas de teléfono corresponden al diseño responsive de la web, no al APK Android.
- No se accedió a cuentas privadas ni se utilizaron perfiles de demostración para esta galería.

La captura de estadísticas puede tener una altura mayor que el área de navegación porque muestra el documento completo. No se recortaron, compusieron ni generaron pantallas para simular funciones.

## Actualizar las imágenes

1. Abrir la web publicada y esperar la carga de los reportes, tiles e imágenes.
2. Utilizar las mismas áreas de navegación de la tabla para mantener el encuadre.
3. Cerrar avisos o ventanas transitorias que no formen parte de la función mostrada. Mantener la atribución cartográfica y el contexto de la aplicación en la documentación.
4. Tomar la captura desde el navegador, sin modificar los datos ni el aspecto de la página.
5. Sustituir el archivo correspondiente y revisar su visualización en el README de GitHub.
6. Actualizar la fecha y el origen si se utiliza otra publicación.

Los números y reportes reflejan el momento de la captura y pueden variar con el uso de EcoMap.
